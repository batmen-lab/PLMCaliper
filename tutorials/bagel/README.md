### BAGEL4 Bacteriocin Analysis

Directory:

```text
tutorials/bagel/
```

This experiment evaluates PLM-Caliper for FDR-guided annotation of putative bacteriocins using the BAGEL4 database. The analysis runs protein retrieval with PLM-Caliper to identify candidate bacteriocin homologs while controlling the expected proportion of false discoveries.

The whole experiment is in the notebook [`bagel.ipynb`](bagel.ipynb), which provides a step-by-step tutorial that shows how this experiment is run and how to reproduce its results.
